# DSA and Coding Roadmap (Java)

The goal is reliable problem solving under interview conditions. Learn patterns, not isolated solutions. Target roughly 70–100 carefully selected problems over 12 weeks, including repeated attempts.

## Required problem-solving routine
1. Restate input, output and constraints.
2. Ask clarifying questions and identify edge cases.
3. Start with a brute-force approach.
4. Improve it and explain why the complexity changes.
5. Implement clean Java code without relying on autocomplete/AI.
6. Test normal, boundary, empty and duplicate cases.
7. State time and space complexity.
8. Re-solve later from a blank editor.

## Java coding checklist
- Use List, Map, Set, Deque, Queue, PriorityQueue and Arrays appropriately.
- Know ArrayList vs LinkedList, HashMap vs TreeMap, HashSet vs TreeSet.
- Understand equals/hashCode contract and immutable keys.
- Use StringBuilder for repeated string construction.
- Use comparator/lambda syntax confidently.
- Know primitive vs wrapper types, overflow, null and Optional.
- Be comfortable with arrays, generics and common collection APIs.
- Write small helper methods; avoid overengineering.

## Weekly DSA target
- Weeks 1–2: arrays, strings, maps, two pointers, sliding window, prefix sum.
- Weeks 3–4: stack, queue, linked list, binary search, trees and BST.
- Weeks 5–6: heap, intervals, sorting, graph BFS/DFS.
- Weeks 7–8: backtracking, greedy, DP foundations.
- Weeks 9–12: mixed sets, timed practice, company-tagged practice and weak-area repair.

Aim for 8–12 new/selected attempts per week plus 5–8 re-solves. Quality and recall matter more than raw problem count.

## Rusty-coding recovery
For the first two weeks, solve easy problems slowly and narrate every line. Do not begin with hard problems. Use a 35-minute attempt limit, then inspect a hint, close the solution and implement independently. Keep a mistake log and revisit failures after 1, 7 and 21 days.

## Interview communication
Say the approach before coding. Explain invariants and trade-offs. Ask whether constraints permit extra memory or sorting. If stuck, communicate what you have ruled out and continue with a correct baseline.
