## Interview readiness checklist
- [ ] Explain 2–3 major projects end-to-end with clear personal contribution and trade-offs.
- [ ] Solve common easy/medium DSA patterns in Java without AI assistance.
- [ ] Explain Java collections, JVM, concurrency and Spring transaction behaviour.
- [ ] Design a scalable backend service and discuss failure modes.
- [ ] Complete LLD exercises with clean interfaces and tests.
- [ ] Explain one production-style RAG system and its evaluation/security approach.
- [ ] Explain MCP and safe tool invocation.
- [ ] Complete at least 3 coding mocks and 3 system-design mocks.
- [ ] Resume and LinkedIn reflect backend/platform engineering strengths.
- [ ] Maintain an active, targeted application pipeline.
